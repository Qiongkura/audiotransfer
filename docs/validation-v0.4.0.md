# 0.4.0 唱音边界识别验证

2026-10-15，完整孙燕姿《我怀念的》录音，未使用歌曲专用简谱或人工填写音符。

## 最终行为

桌面版默认“唱音识别（试用）”，设置中可以切回“连续音高（兼容）”。命令行通过 `--song-backend game` 启用，默认保留 `rmvpe` 兼容行为。

RMVPE、CREPE 及分离轨能量继续确定演唱区域。GAME Small 1.0.3 在这些区域内给出完整唱音的起止与稳定音高；演唱中的休止不回退到伴奏。前奏、独立间奏与尾奏仍跟踪乐器，纯音乐不调用 GAME。新模式跳过《茶汤》的录音指纹校谱快捷匹配。

每个 GAME 输入片段最长 13.2 秒，采用 CPU、4 个计算线程、8 步识别。片段两侧各保留最多 600 ms 上下文。只有两侧都预测同一延音跨越接缝时才合并；真正的同音重复保持独立。唱音输出不再经过逐帧平滑、最短 80 ms 合并或节拍网格吸附。

模型压缩包与各模型文件分别校验 SHA-256，部分下载会继续请求缺失区间，未经校验的文件不会安装。模型与识别缓存存放在项目 `.models/game/`。GAME 模型限非商业用途，见[模型来源与许可](GAME-NOTICE.md)。

短乐器区段沿用 0.3.2 定义：不超过 950 ms，且左右最近的人声区段均距其边界不足 1500 ms。所有输出频率有限且非负。转换与完整试听生成成功，本机复用分离轨和基音缓存后用时约 54 秒。

短音统计包含真实快音，不能把减少的 243 个事件全部称为错音，也不能用事件数量直接推断主观听感或逐音准确率。新模式仍可能出现音高、边界和主唱判断错误，因此保留兼容模式。
